# Banned and Restricted Pesticides in India

## General Advisory
The Ministry of Agriculture and Farmers Welfare strictly prohibits or restricts the use of certain highly hazardous pesticides. Advisory agents MUST NEVER recommend these chemicals under any circumstances.

## Completely Banned Chemicals
Never recommend any of the following for agricultural use in India:
- Aldrin
- Chlordane
- DDT
- Endosulfan
- Lindane
- Monocrotophos (Banned for use on vegetables)
- Phosphamidon
- Dicofol

## Restricted Use Chemicals
These chemicals should only be recommended if specifically prescribed by a certified local KVK officer for a specific outbreak where no alternatives exist:
- Glyphosate (Restricted use, only by pest control operators)
- Carbofuran (Granular formulation only, avoid widespread spray)

**Agent Instruction:** If a user explicitly asks about using a banned chemical (e.g., "Can I use Endosulfan on my cotton?"), you MUST strongly advise against it, state that it is illegal/banned due to health and environmental risks, and suggest the safer, approved alternatives for their specific pest issue.
